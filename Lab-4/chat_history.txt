  1. Combo bonus (board.py (../57_match_three_gem/game/board.py), game_engine.py
  (../57_match_three_gem/game/game_engine.py))
  - Each round of falling and matching again multiplies its points by 1x, then
    2x, then 3x, and so on. resolve_matches() now returns the points itself, and
    process_swap() adds them to the score.
  - When a swap sets off 2 or more rounds, "COMBO xN!" appears in gold in the
    middle of the board for 1.2 seconds. N is the highest round reached, and a
    plain single match shows nothing.

  2. Bomb gems (board.py (../57_match_three_gem/game/board.py))
  - A match of 4 or more leaves one bomb behind. The bomb keeps its color so you
    can match it again later. It goes on the cell you swapped into, or the
    middle of the line if the match came from gems falling.
  - It has a pulsing white outline and a white dot in the centre.
  - A bomb matched in a row clears that whole row, and one matched in a column
    clears that column.
  - Some choices I made myself that you can change:
    - If a blast hits another bomb, that bomb also goes off, clearing the other
      direction.
    - Every gem cleared scores, including the ones a blast removes.
    - A new board never starts with bombs.
  - To support this, find_matches() now builds on a new find_runs(), which finds
    whole lines of the same color (the old code only checked groups of 3). It
    still returns the same thing, so the rest of the code works as before.

  3. Idle hint (game_engine.py (../57_match_three_gem/game/game_engine.py))
  - After 5 seconds without a click, and only when the board has stopped moving
    and the game isn't over, two swappable gems get a pulsing yellow outline.
  - Any click, or pressing R, hides it and restarts the 5-second timer.
  - If the board has no possible moves, no hint shows. The game has no reshuffle
    for that case, and I didn't add one.
